# Real Estate Price Prediction

## Machine Learning Based Residential Property Price Prediction

### 📌 Project Overview
This project develops an end-to-end machine learning model to predict residential house prices using the Ames Housing dataset. The project covers data cleaning, exploratory data analysis (EDA), and machine learning model comparison to help support real estate investment and pricing decisions.

The final selected model is a tuned **Gradient Boosting Regressor**, which explains roughly **81.9%** of the variation in housing prices.

---

### 📂 Project Structure
* `Data/` - Contains the training and testing datasets.
* `Notebooks/` - Contains the Jupyter notebook with the full machine learning code.
* `Outputs/` - Contains the final `predictions.csv` file generated by the model.

---

### 🛠️ Tech Stack
* **Language:** Python 3
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

---

### 📊 Key Insights & Results
* **Best Model:** Tuned Gradient Boosting Regressor (Validation RMSE: ~35,538.86).
* **Top Predictors:** The overall material and finish quality (`OverallQual`) and above-ground living area (`GrLivArea`) are the most critical factors in determining a home's value.
